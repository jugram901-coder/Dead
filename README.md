# DeadPlayer

A private, offline-friendly music player that runs in the browser. Your songs stay on your device (IndexedDB) and are never uploaded.

- Themes: Pink & Black, Red & Black, Black & Gray
- Equalizer, visualizer, queue, playlists, synced lyrics, sleep timer
- Installable on iPhone / Android / desktop (Add to Home Screen)

Open the GitHub Pages link for this repo, then Share -> Add to Home Screen.
